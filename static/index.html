      Ctrl+Z — отменить, Ctrl+X — вернуть. У края холста указатель удерживается внутри изображения. «Заливка области»: обведите контур; незамкнутый контур соединится прямой линией. «ИИ: только облака»: обведите участок — внутри контура ИИ выделит красным только распознанные облака. Красная заливка может заменить синие метки; существующие красные сохраняются, синяя заливка не проходит через красные.
